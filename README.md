# HomeFund

A family budget web app. Set your payday and HomeFund shows how much money is left until the next payday and how much you can spend per day. Snap a receipt and it is cropped, read line by line and sorted into categories automatically.

## Features (in progress)

- Payday countdown and daily allowance
- Manual expense entry
- Receipt scanning with SAM 3.1 and Muse Spark 1.3 (Meta Model API)
- Voice expense entry with Muse Voice Transcribe
- Shared household with a budget per member
- Currencies: EUR, RON, HUF

## Built during the hackathon

Everything in this repository was built from scratch during the Meta Global AI Developer Hackathon (October 27 – November 4, 2026). No code existed before the event.

## Tech stack

- Next.js, TypeScript, Tailwind CSS
- Meta Model API

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.
